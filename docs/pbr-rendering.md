# 无光影包 PBR 渲染

新增客户端内置渲染功能，默认开启，不需要安装或启用光影包。读取 TaCZ 模型实际使用的贴图，支持普通枪身、双持枪身，以及经过 TaCZ BedrockModel 标准路径渲染的配件。没有对应 `_s.png` 时不添加材质反光，但仍支持模型发光组泛光。

## 材质约定

对 `namespace:textures/gun/example.png` 自动查找同目录的 `example_s.png` 和可选的 `example_n.png`。遵循 **LabPBR** 编码，旧版 SEUS、ORM、RMA 打包方式需先转换：

| 贴图通道 | 含义 |
| --- | --- |
| `_s` R | 平滑度，越高反光越集中 |
| `_s` G | 0–229 为非金属 F0；230–237 为预定义金属；238–255 为使用底色的金属 |
| `_s` A | 0–254 为自发光强度；**255 表示不自发光** |
| `_n` RG | 切线空间法线 XY，重建 Z |
| `_n` B | 环境遮蔽 |

目前不使用 `_s` B 的孔隙/次表面信息，也不做视差位移。GGX 高光每帧读取世界的天体角度，与原版天空的太阳/月亮位置一致，并考虑相机方向、材质法线和粗糙度。太阳接近地平线时偏暖；月光较弱且偏冷，亮度随月相变化；降雨和雷暴会减弱直射高光。天空/地面环境反射仍采用颜色近似，其亮度随昼夜变化。

直射高光根据顶点及相机处的天空光照衰减，并从相机朝日月方向检查 96 格内的方块碰撞体遮挡，天花板或墙壁挡住光源时关闭直射高光。环境色反射改为弱的、受材质底色影响的反射，并随天空光照衰减，避免室内火把将整把枪照成偏白。遮挡结果以相机为参考，主要服务第一人称持枪，不是逐表面或逐实体的阴影贴图；远处实体也会使用相机的遮挡结果。下界、末地等没有原版日月天空的维度禁用日月光源。自定义天空模组改动的天体轨迹目前不接入。反光不会反射周围实体的完整倒影。

泛光来自 TaCZ 标记为 `illuminated` 的模型组（名称含 `_illuminated`）及其子组，或枪械材质中的自发光像素。模型发光组无需 `_s.png`，发光颜色采用基础贴图颜色，两种发光来源取较大值。不会根据画面亮度将天空、白色枪身或 HUD 一起模糊。这里的“发光块”指枪械模型上的自发光部分，不包含世界方块的全局泛光，也不改变世界照明。

## 配置

首次启动后生成 `config/taczfixes/pbr.toml`，与其他配置一样按段落注册，效果仅影响客户端画面：

```toml
[pbr]
enabled = true
reflection_strength = 1.0
emission_strength = 1.0
bloom = true
bloom_strength = 0.6
bloom_radius = 6.0
```

`reflection_strength`、`emission_strength` 范围为 0–4；`bloom_strength` 为 0–3；`bloom_radius` 为 1–24 屏幕像素。关闭 `bloom` 可保留材质反光及自发光，减少开销。可在模组配置界面的“PBR 反光与泛光”分类中修改并保存。旧的 taczfixes-pbr-client.toml 不再读取；需要保留旧设置时，可将其内容复制到新文件。

## 渲染与兼容

- 模型沿用原来的透明、裁剪、光照、覆盖色和纹理状态，用同一份上传后的几何绘制材质与发光遮罩，避免重复执行模型动画或配件逻辑。
- 自发光遮罩保留深度，采样主画面的深度并复制瞄具模板遮罩；模糊前再次检查遮挡。
- 在第一人称手部清除深度之前合成世界泛光，手部结束后再合成持枪泛光，HUD 不参与。
- 泛光采用全分辨率两遍高斯模糊，避免细准星的发光像素在降采样时被跳过。相较旧版半分辨率处理增加显存和屏幕处理开销。
- 发光图使用线性过滤，模糊逐像素采样，避免稀疏采样产生网格状重影。`bloom_radius` 作为高斯标准差，采样延伸到其两倍距离；大半径比旧版需要更多采样。合成亮度系数为旧版的 1.6 倍，可用 `bloom_strength` 调整。
- 发光标记直接进入 BedrockPart.compile 的光照参数，不依赖替换顶点消费者。包含父组继承和直接 compile 绘制路径。
- 启动后限次输出 `[TaCZ PBR]` 诊断，包含发光组名称、标记顶点数、采集是否启用，以及发光/模糊纹理的非黑像素数量和峰值；最多三次 GPU 读回采样，间隔至少五秒，之后不再读回。
- F3+T 资源重载会清理材质缓存和显存资源；窗口分辨率变化会重建泛光缓冲。
- Oculus 或 OptiFine 启用光影包时自动回退。无法查询 OptiFine 状态时保守回退。
- 与 Accelerated Rendering 共存：PBR 开启时让 TaCZ 的枪械、配件及瞄具走普通路径，以便材质和泛光即时采集。PBR 关闭时，手持枪械任意自定义槽装有瞄具（含备用、默认原厂瞄具、红点与全息）也回退到普通绘制；主手、副手及第一、第三人称左右手均适用，按每把枪分别判断。卸下自定义槽瞄具后恢复原有加速选择；标准槽瞄具、空自定义槽和非瞄具配件不会触发这项回退，GUI 与掉落物也不受这项手持规则影响。无自定义槽位的枪械跳过额外瞄具处理；加速路径中的自定义配件在枪身 AR 回调入栈之前提交，不再执行即时模板修复或重绘标准瞄具。完整游戏验证尚待执行。
- PBR 保留原版光照后的底色亮度，不再将金属底色额外乘以 0.55；环境反射仍保持低强度，日月直射与天空反射仍受室内遮挡衰减。
- 非主帧缓冲绘制（包括部分 Fabulous/第三方离屏通道）不会采集泛光；这类通道仍可使用材质着色。建议先用原版“流畅/高品质”图形设置验收。

## 验证

项目编译及打包：`gradlew.bat --offline build`（本地依赖齐全时）。

Windows、JDK 17、本地 Forge/LWJGL 缓存齐全时可运行：

```powershell
powershell -ExecutionPolicy Bypass -File tools/verify-pbr.ps1
powershell -ExecutionPolicy Bypass -File tools/verify-pbr-vertices.ps1
powershell -ExecutionPolicy Bypass -File tools/verify-pbr-blend.ps1
powershell -ExecutionPolicy Bypass -File tools/verify-pbr-engine.ps1
```

脚本不启动 Minecraft，显卡测试使用不可见 OpenGL 窗口。检查三个着色器的编译/链接、LabPBR Alpha 的 255/254/127 值、无高光贴图的模型发光组、法线分支、深度遮挡、泛光扩散及叠加；另外验证发光顶点标记和嵌套包装，并回归检查原版暗角绘制的混合状态。该测试不替代完整游戏验证。

游戏验收步骤：

1. 禁用光影包，分别在安装和未安装 Accelerated Rendering 时使用带 `_s` 的枪械。晴天室外转动视角，比较金属部分和非金属部分。分别用 `/time set 1000`、`/time set 6000`、`/time set 11000` 和 `/time set 18000` 检查日月位置对应的高光变化；用 `/weather rain` 对照天气衰减。再检查洞穴、下界和末地不会出现日月直射高光。
2. 使用带 `_illuminated` 组的枪械，在暗处观察其部件及子组周围的柔和泛光；关闭 `bloom` 对照。无 `_s.png` 的枪也应有效。另用未标记发光组的测试材质验证 A=254 发光、A=255 不发光。确认白色非发光区域不泛光。
3. 检查第一人称、第三人称、掉落物、双持及配件；在墙后观察枪械，不应出现自发光源穿墙泄漏。
4. 检查开镜、镜片遮罩、换弹、检视、透明皮肤和 GUI 预览，确认没有状态污染。
5. 安装 AR 时，分别以 PBR 开启和关闭状态启动游戏，并在持有瞄具枪械时反复切换 PBR；检查未开镜、开镜、切换瞄具及双持时均无黑色方片、丢失模型或残留泛光。
6. 改变窗口尺寸、切换全屏、执行 F3+T、切换世界，并切换泛光开关；应没有上一帧的光晕残留。
7. 启用 Oculus/OptiFine 光影包，确认自动回到其原渲染路径。
